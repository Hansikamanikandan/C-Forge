# 📖 About

Welcome to my **Basic C Programming Collection**.

This repository contains carefully written C programs that helped me strengthen my understanding of programming fundamentals during my engineering journey.

The programs focus on developing problem-solving skills using basic C concepts such as variables, operators, conditional statements, mathematical formulas, user input, and standard library functions.

Every program is written with readability, simplicity, and proper coding practices in mind, making this repository useful for beginners who are starting their C programming journey.

# ▶ Running the Programs

### Compile

```bash
gcc filename.c -o output
```

Example

```bash
gcc 07_simple_and_compound_interest.c -o interest
```

Run

**Windows**

```bash
interest.exe
```

**Linux / macOS**

```bash
./interest
```
